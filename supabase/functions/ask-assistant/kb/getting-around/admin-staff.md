The [Admin Staff](/admin-staff) page is the direct-contact list for WCEMS administrative staff — each card shows a title, name, phone (tap to call), email, and any notes. Use it when you need "the right person" for HR, payroll, scheduling, clinical development, supplies, and similar questions.

Find it from the phone menu (☰ → Admin Staff) or Ctrl/Cmd+K search — on desktop there's no nav entry, so search is the quickest path.

Admins maintain the list at [Manage Admin Staff](/admin/admin-staff): add entries (Title, Name, Email, Phone, Notes, and an "Active (visible to crew)" toggle), edit, reorder with the arrows, or delete. Changes show up for everyone in real time.
