To refer a patient to Mobile Integrated Healthcare (the community paramedic program), open [MIH Referral](/mih-referral) — any signed-in employee can submit one.

Ways in: the dashboard's "Refer a patient to MIH → Start a referral" card, the mobile quick strip, or the nav ("MIH Referral" on desktop, "MIH Patient Referral" in the phone menu).

The page embeds the Patient Referral form — fill it out and submit right there. If the form doesn't load, use the "Open it in a new tab" link on the page.

The referral goes to the MIH / community paramedic team. For questions about an existing referral or the program itself, contact the Community Paramedic via [Admin Staff](/admin-staff). (The MIH team's own tracking tool is a separate app — crews only need this referral form.)
