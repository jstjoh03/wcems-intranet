[Badge Maker](/admin/badge-maker) designs and prints CR80 employee ID cards (2.125 × 3.370 in) sized for direct printing on the Badgy card printer. It's a full-screen tool with its own roster, saved automatically so any admin can reprint from any machine.

Per card: name, title, badge number, expiration and issue dates, provider level with its accent/band color, a photo with zoom and position controls, and back-of-card certification numbers (Texas DSHS, RN/BON, NREMT) plus agency settings (medical director, return address).

Roster controls: Add person, Duplicate, Delete, and Save/Load roster file for JSON backups. Printing: **Print front**, **Print back**, or **Print both**, with a "Slot-punched cards" toggle that keeps the punch area clear.

Note its roster is its own list — it doesn't read from Manage Employees, so new hires are added here manually when their badge is made.
