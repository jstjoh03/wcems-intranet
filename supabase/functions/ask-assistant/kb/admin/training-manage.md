Three surfaces split the training admin work:

**[Manage Classes](/admin/training)** (admins): the synced class calendar — Wix Bookings + the education calendar, refreshed every 15 minutes. Here you can **Sync now**, set the instructor name per session, and **Exclude** a Wix service (its sessions disappear and stay excluded) or re-include it.

**[Instructor area](/training/manage)** ("Manage Card Classes & Lectures" — gated by the training-instructor list, separate from portal roles): the full class workflow. **Create** publishes an AHA card class (creates the Wix booking) or a CE lecture (in-app registration). **Controls** per course: check-in/evaluation toggles, QR codes (Check-In, Eval, Quiz, Engage), edit details (date changes move the Wix event too), AHA roster PDF, Award CE Credits (generates certificates for qualified attendees — checked in + eval, quiz passed if required), Close Course, and Cancel Course (cancels the Wix event; Wix notifies bookers). **Registrations**, **Rosters/Evals exports** (archived to the record store), and **Access** (training admins only) — add instructors with their AHA number and authorized disciplines.

**[Manage Training Library](/admin/training-recordings)** (admins): post recordings — title, instructor, category, tags, video source (Wix Media / SharePoint / YouTube unlisted / direct URL), optional thumbnail, role visibility, and Published. View counts show per row.

Required-training modules are separate — see the required training admin article.
