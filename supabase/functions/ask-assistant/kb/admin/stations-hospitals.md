**[Manage Stations](/admin/stations):** add or edit stations — ID (fixed once created), name, address, city/ZIP, phone, map URL, door code ("App Access" or numeric), and the Active toggle. Deactivate hides a station from crews; delete is permanent.

**[Manage Hospitals](/admin/hospitals):** add or edit hospitals — name, trauma designation, stroke designation, PCI, pediatric, maternal, NICU, address, map URL, ER door code and EMS room code (or "No door code (ring door bell)"), code effective date, notes, and Active.

Day-to-day **door-code corrections don't need these pages** — any signed-in user can update a code inline on the dashboard Station Directory or a hospital card, and every change is logged with name and time. These admin pages are for the facility records themselves.

Crews see the results at [Hospitals](/hospitals) (filterable by trauma/stroke/PCI/pediatric/maternal, sorted by trauma level) and the dashboard Station Directory.
