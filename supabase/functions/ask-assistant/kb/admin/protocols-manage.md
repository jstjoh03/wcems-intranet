[Manage Protocols](/admin/protocols) edits the live protocol content. Reach it from the Protocols app → **More** tab → **Admin** (it's not in the Admin menu).

Pick a protocol from the dropdown, then edit its criteria (Adult / Pediatric / general notes) and the step lists per level — add steps, warnings, branching conditions, and medical-control items — then **Save Protocol**.

Important characteristics:

- **Changes go live immediately** — there's no draft or approval step. Online users see the new text on their next load; devices using Download-for-Offline keep their cached copy until they reconnect or re-download.
- Only protocol *content* is editable here: names/numbers/categories, procedure body text, the medication reference, the formulary, the equipment list, and the tools have no in-app editor — those changes go through the protocol book process with the CDO.

Given protocol text is medical direction, treat this page with the same care as the printed book: coordinate edits with the Medical Director and announce meaningful changes (Required Training video + skills verification was the 2026 pattern).
