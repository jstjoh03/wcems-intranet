title: Publishing announcements

route: /

Announcements are posted straight from the dashboard's Announcements card — tap **+ New** (admins only; there's no separate admin page).

Compose: **Headline** (required), a category (Operations / Protocol / Education / Recognition / Outreach / Event / Other with custom text), the body (Bold, Italic, links, bulleted lists, with a Preview toggle), an optional image up to 5 MB, and **Allow comments** — which adds a "Notify on new comments" person picker so the right people hear about replies. Then **Publish**.

**Publishing a new active announcement push-notifies every subscribed device** ("{Category}: {Title}"). Only the initial publish notifies — edits, archive/restore, and deletes are silent, so typo fixes don't re-ping the agency.

Each post has Edit, **Archive** (reversible; archived posts hide from crew but stay under "Show archived"), Restore, and Delete (permanent). Multiple active announcements rotate in the carousel, newest first.

Tip: crew don't see the Announcements card at all when nothing is active, and the image shows best around a 7:5 landscape ratio (it's never cropped). For scheduling-specific blasts (page-outs with text message support), use Schedule → Page-outs instead — that's a separate system.
