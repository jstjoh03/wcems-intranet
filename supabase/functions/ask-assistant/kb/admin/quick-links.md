[Manage Quick Links](/admin/quick-links) owns the org-wide link catalog that feeds the phone Quick Links dock, the desktop Systems menu, the utility-bar system links, the dashboard featured-tiles picker, and global search.

**Add link:** Label, Subtitle, URL, Category (free text with suggestions), Icon (a Lucide icon name — falls back to a generic link icon), **Sort order** (lower = first within its category), **Visible to** (crew/supervisor/admin — all unchecked means everyone), and **Active**.

Rows are grouped by category with Deactivate, Edit, and Delete. Reordering is by the sort-order number — there's no drag-and-drop. Changes reach everyone's dashboard in real time.

Notes: crew pin their personal favorites in the dock themselves, and pick their own featured tiles — you manage the catalog, not their choices. Some tiles are matched by exact label (the role-default featured tiles, the "Patient Referral Form" used by the MIH page, "Employee Shoutout") — renaming those labels breaks the match, so keep names stable.
