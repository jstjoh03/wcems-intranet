Scheduling admin lives inside [Schedule](/schedule) under the **Manage** menu. Editing power belongs to the **Global admin** and **Scheduler** access levels — a portal admin defaults to only Supervisor-level schedule access until granted more.

- **Access grants:** Members → open a person → the **Access** dropdown (Global admins only): Scheduler, Supervisor (can send page-outs), HR (payroll only), View only, No access. The same panel sets credential overrides, position qualifications, unit exclusions, and "Hide from scheduling".
- **Units & seats:** Setup → "Units & display order" — add units (code, label, station, seat preset), set each unit's rotation (agency default 48/96 B-B-C-C-A-A or a custom pattern) and daily shift hours, reorder, deactivate.
- **Rotation template:** Setup → "Rotation template — who holds each seat, per shift". Click a cell, type a name, set the **Effective** date (clashes offer Swap / Move only). This table is also what drives everyone's profile shift/station and the GAL office field — change seats here, never on profiles.
- **Approvals:** the Requests tab is the work queue — time off, pickups, extra hours, trades, and time discrepancies, with Approve / Deny / Edit times.
- **Events:** click a day → "Add a special event" (name, window, Paramedic/Attendant seat counts, location, double-time toggle). Event rosters can drive event-tied required training.
- **Page-outs:** compose push/email/text blasts, optionally attaching open shifts, to a filtered roster.
- **Payroll:** Time Reports → Verify punches, Hours, Paycom export, Sign-offs, Balances; Setup → "Paycom earning codes" (Global admin/HR) maps categories to codes.
- Day tools: "+ Add to this day" (events, notes, students, extra seats, record time off / extra hours) and the person editor (change times, mark off, move, replace).
